# Contribuir a Visual Web

Las aportaciones útiles son nuevas referencias bien documentadas, mejoras del método, correcciones de portabilidad y pruebas que detecten fallos reales.

## Añadir una referencia

1. Lee el [protocolo de captura](skill/visual-web/references/capture-protocol.md).
2. Guarda capturas reales de escritorio, secciones interiores y móvil con su procedencia.
3. Abre cada imagen y separa lo observado de lo que propones adaptar.
4. Reconstruye el catálogo y ejecuta `npm test` y `npm run check`.

No envíes pantallas de error, contenido privado, activos extraídos para reutilización, análisis inventados ni afirmaciones sobre tecnologías o animaciones que no se hayan observado.

Para una mejora del flujo, explica el problema concreto, el comportamiento propuesto y cómo lo comprobaste. Mantén el lenguaje sencillo: esta herramienta también está pensada para personas con poca experiencia técnica.
