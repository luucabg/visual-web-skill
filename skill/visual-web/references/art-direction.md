# Dirección de arte: decisiones transferibles

El objetivo es que producto, imagen, texto y movimiento cuenten la misma idea. No existe un único aspecto Awwwards. Una página calmada puede ser tan deliberada como una experimental.

## Elige según el contenido

| Necesidad del proyecto | Dirección que puede servir | Riesgo que debes controlar |
| --- | --- | --- |
| Arquitectura, hospitalidad, artesanía | Fotografía material, composición editorial, pocas acciones | Espacio vacío sin información, fotos que prometen lugares o productos inexistentes. |
| Producto físico | Macrofotografía, escena de uso, escala y materiales consistentes | Inventar piezas, variantes o funciones al generar imágenes. |
| Software y herramientas | Jerarquía clara, demostración de producto real, ejemplos concretos | Pantallas ficticias bonitas que no explican el producto. |
| Estudio creativo o portfolio | Tipografía expresiva, secuencia de proyectos y cambios de escala | La navegación compite con el trabajo que debe mostrar. |
| Marca cercana o educativa | Ilustración coherente, color y narrativa accesible | Personajes decorativos sin función o tono infantil no deseado. |
| Experiencia cultural o campaña | Una interacción distintiva y una narrativa espacial | Ocultar contenido tras carga lenta, WebGL obligatorio o gestos no descubribles. |

Estas son opciones, no plantillas obligatorias. Una referencia de software puede enseñar espaciado a una web editorial; una de moda puede enseñar encuadre a un producto técnico. Explica qué transfieres y por qué.

## Fotografía que funciona dentro de la web

- Decide qué debe mirar primero el visitante y dónde vivirá el texto. Pide espacio útil para ese texto, no un fondo aleatoriamente vacío.
- Describe sujeto, acción, plano, perspectiva, luz, material y tratamiento de color. `Premium`, `cinematic` o `award winning` no sustituyen esas instrucciones.
- Mezcla contexto, detalle y escala humana cuando aporten información. No repitas la misma toma con pequeños cambios en todas las secciones.
- Mantén una familia reconocible: temperatura de color, contraste, textura y tratamiento de sombras compatibles. Una escena nocturna puede convivir con una diurna si se decide su función.
- Define antes los recortes desktop/móvil y las zonas que no pueden perderse. No arregles un sujeto mal situado con texto ilegible encima.

## Tipografía y composición

La jerarquía debe sobrevivir sin imágenes: título, apoyo, acción. Estima ratios desde referencias, elige valores CSS después de probar texto real. Controla el largo de línea y los saltos antes de reducir la fuente indiscriminadamente.

Alterna vistas amplias con momentos densos y detalles cercanos. Usa un sistema de márgenes, alineaciones y relaciones de aspecto; una asimetría intencional aún necesita relaciones claras. Los paneles y tarjetas se justifican por agrupación o interacción, no por llenar huecos.

Evita convertir preferencias estilísticas en prohibiciones universales. Un gradiente, un bento, una marquesina o un fondo blanco pueden ser correctos si explican el producto y no reemplazan contenido necesario.

## Movimiento

Asigna una función a cada efecto: entrada para jerarquía, transición para continuidad, movimiento de producto para explicar forma. Define desencadenante, elemento, estado inicial/final y alternativa sin movimiento. Los tiempos y curvas son decisiones de implementación hasta comprobarlos, no hechos extraíbles de una captura.

No copies el control del scroll de una web experimental a un sitio transaccional por prestigio. En móvil, teclado y movimiento reducido, todo contenido y acción deben seguir disponibles.
